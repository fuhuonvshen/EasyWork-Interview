# EasyWork 使用教程

> EasyWork：会议录音 → 自动转文字 → AI 写纪要 → 日程提醒 → 待办管理 → AI 助手。全部本地处理，数据不出电脑。

---

## 一、安装（选对版本）

下载地址：**GitHub Releases** → `github.com/fuhuonvshen/EasyWork/releases/latest`

| 系统 | 下载哪个 | 安装方法 |
|------|---------|---------|
| Windows（x64） | `EasyWork_x.x.x_x64.msi` | 双击 MSI，自动静默安装完成 |
| macOS（Apple 芯片 M1/M2/M3…） | `EasyWork_x.x.x_aarch64.dmg` | 打开 dmg，把 EasyWork 拖进"应用程序" |

> 当前最新版本：1.0.5。没有其他架构的版本，看清自己的系统选对应的即可。

---

## 二、首次设置：下载模型（必须做）

打开软件 → 工作台 → 右下角 **设置**，弹出"模型管理"（三个标签页）。

### 会议纪要 页（转写 + 纪要）

| 下载什么 | 大小 | 说明 |
|---------|------|------|
| **SenseVoice**（或 **Whisper small**） | 488 MB+ | 语音识别。纯中文会议选 SenseVoice，中英混合选 Whisper small |
| **推理引擎 llama-server** | 见右列 | 🪟 Windows 手动点"下载"，**自动区分版本**：有 NVIDIA 显卡（装了驱动）下 **CUDA GPU 版（约 240 MB**，更快）；没有则下 **CPU 版（约 20 MB）**。🍎 macOS 显示"已就绪"（Metal GPU 加速，仅约 10 MB），跳过 |
| **Qwen 3.5 4B** | 约 2.6 GB | 纪要生成。配置低选 Qwen 3.5 2B（1.2 GB） |

点模型卡片上的"下载"，等进度条完成。

### 办公助手 页（AI 对话）

二选一：

- **本地模型 (llama.cpp)**：选此项 + 下载一个 Qwen 模型。免费离线。
- **在线模型 (OpenAI 兼容)**：填三项，**保存后重启生效**。

| 填写项 | 示例 |
|--------|------|
| API Key | `sk-xxxx`（服务商官网申请） |
| 模型名称 | `deepseek-chat` / `qwen-plus` / `gpt-4o` |
| API 地址 | `https://api.deepseek.com`（DeepSeek、阿里云百炼、OpenAI 均可，地址带不带 `/v1` 都行） |

### 通用设置 页（顺手配好）

- **开机自启动**：开（推荐）
- **默认启动页**：工作台 / 会议纪要 / 办公助手
- **数据根目录**：模型和录音存放位置，默认用户目录，可改到别的盘（改后重启）

全部配好点 **保存**。

**速查**：电脑好 → 全用本地（SenseVoice + Whisper + Qwen 4B）；配置一般 → 纪要本地 + 助手在线；要最强效果 → 助手 gpt-4o。

## 三、界面一览（全部菜单）

**工作台**（首页）：四张功能卡片——**会议纪要** / **共享屏幕**（即将上线）/ **办公助手** / **意见反馈**；底部 **设置**（模型管理入口）

**会议纪要**（左侧边栏，共 3 项）：
- **今日会议**：录制、实时转写、生成纪要
- **历史纪要**（含 3 个子菜单）：**会议记录**（历次纪要，查看/编辑/导出）、**周报**、**月报**
- **日程**：日历视图、会议提醒、新建/编辑/删除

**办公助手**（左侧边栏，顶部 2 个切换 tab）：**对话** / **待办**（带未完成数量角标）

**意见反馈**：给开发者提意见

---

## 四、开会（核心功能，4 步）

1. **会议纪要 → 今日会议**
2. **选录音来源**：
   - 🪟 Windows 线上会议：选默认（系统音频）设备，**能同时录你和对方**；面对面选"麦克风"
   - 🍎 macOS：只能选"麦克风"，**录不到对方声音**（线上会议需第三方虚拟声卡如 BlackHole，或用外放收音）
   - 填会议标题（如"周例会"）、选类型（通用/周会/培训/项目评审/面试）
3. **点"开始录制"**：实时转文字，自动标注说话人（我/发言人/参会者_N）
4. **点"结束录制"**：自动生成纪要弹窗（**会议总结** + **转写记录**两页）

已有录音文件？今日会议页点 **导入音频文件**（mp3/wav），同样转文字出纪要。

---

## 五、历史纪要（含周报月报）

**会议纪要 → 历史纪要**（3 个子菜单）：

- **会议记录**：搜索、筛选、置顶、批量删除；点开会可**编辑**纪要，**导出** Word / Markdown / PDF / 图片
- **周报 / 月报**：查看已生成的一周/一月报告，可删除

---

## 六、日程

**会议纪要 → 日程**：

1. **新建日程**：标题 + 起止时间 + 会议链接（选填）
2. 到点**自动弹提醒**（首次需允许系统通知）
3. 点某天 → 详情面板：编辑 / 删除 / 跳转该会议纪要
4. 新建日程**自动生成对应待办**
5. **生成周报 / 月报**：AI 按会议记录自动汇总，生成后到"历史纪要 → 周报/月报"查看

---

## 七、AI 办公助手

**办公助手**：左侧边栏顶部 **对话 / 待办** 两个 tab，右边聊天窗（Enter 发送，支持拖拽上传 Excel/CSV/TXT）。

| 目的 | 输入 |
|------|------|
| 记待办 | "帮我记一下：周五之前给王总发报价单" |
| 排日程 | "下周一下午3点和张经理开会，记到日程" |
| 分析表格 | 拖入 Excel，问"按周汇总产量" |
| 提问 | "我上个月开了几次会？" |

待办：**待完成/已完成**分组，可勾选、标优先级（高中低）、设截止日期；AI 从对话提取的待办自动进列表。对话可重命名/删除，AI 有长期记忆。

## 常见问题

- **没声音？** Windows 检查是否选了系统音频设备；macOS 本来就录不到对方声音。
- **纪要不满意？** 历史纪要里点开直接改，自动保存。
- **导出？** 历史 → 导出 → Word/PDF。
- **数据上传吗？** 默认不上传。仅当助手设为"在线模型"时，对话发给服务商。
- **助手卡顿？** 换小模型（2B）或切在线模型。
- **换电脑？** 拷走"数据根目录"整个文件夹，新电脑设置里指过去即可。
- **模型下载失败？** 文件较大、源在国外，换网络重试，支持断点续传。

## 起步清单

1. 设置里下载：语音模型 → Qwen 4B → 选助手模式 → 保存
2. 会议纪要 → 今日会议 → 开始录制 → 结束录制
3. 看纪要 → 历史纪要里导出 Word
4. 日程新建一个明天的会议
5. 助手输入"帮我记一下：明天上午给老板发周报"

完成这 5 步即可上手。
